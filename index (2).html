01 · LE LANGAGE

Simple à lire.
Puissant à utiliser.

Briks utilise des mots courts et naturels. Pas besoin de mémoriser une montagne de syntaxe avant de commencer.

01

Une syntaxe naturelle

allow, display, if, while, fn… Le code se lit presque comme une phrase.

02

Tout ce qu'il faut

Variables, conditions, boucles, fonctions, listes, objets, texte, entrées utilisateur, modules et gestion des erreurs.

03

Un langage qui grandit

Briks est construit comme un vrai projet : moteur, documentation, exemples, Studio et versions successives.

03 · UN PETIT APERÇU

Ça commence
comme ça.

Quelques lignes suffisent pour créer un programme interactif.

[ Un mini programme Briks ]

ask "Comment tu t'appelles ?" as name
allow message = "Bienvenue " + name
display message

if size name > 5 {
    display "Joli prénom !"
}
